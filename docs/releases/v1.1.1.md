# Mote v1.1.1

**The prompt enhancer and completions in Claude Code's prompt box and VS Code's chat.**

## Highlights

- **Claude Code and Copilot Chat in VS Code are recognized as AI prompts.** Pause while typing a prompt and "Enhance prompt · Tab" appears; Tab rewrites it in place.

## Features

- Claude Code's prompt box ("Message input") and VS Code's chat inputs (Copilot Chat, inline chat) are recognized from their accessible labels. These boxes draw their placeholder text without exposing it to accessibility tools, so 1.1.0 classified them as code unless AI classification decided otherwise.
- Claude Code's "Ask a side question" box is recognized as a prompt too.

## Privacy

No change: the prompt enhancer sends the prompt you are enhancing to Groq only when you press Tab.

## Supported Platforms

| Platform | Minimum | Download |
|---|---|---|
| macOS, Apple Silicon | macOS 11 | `Mote_1.1.1_aarch64.dmg` |
| macOS, Intel | macOS 11 | `Mote_1.1.1_x64.dmg` |
| Windows x64 | Windows 10 or 11 | `Mote_1.1.1_x64-setup.exe` (installs for your account, recommended) or `Mote_1.1.1_x64_en-US.msi` (installs for all users, needs administrator rights) |

The other files are for the in-app updater: `latest.json` lists the current version, macOS updates come from `Mote_1.1.1_aarch64.app.tar.gz` and `Mote_1.1.1_x64.app.tar.gz`, Windows updates run the installers, and each `.sig` file is the signature the app checks before installing.

## Known Limitations

- **VS Code's editors need its screen reader mode.** Claude Code's prompt box works in any mode. Copilot Chat and VS Code's own editors expose their text only in "Screen Reader Optimized" mode, which VS Code offers to turn on once Mote switches on its accessibility tree.
- Everything listed under [1.1.0's known limitations](https://github.com/Prathameshppawar/mote/releases/tag/v1.1.0) still applies.

## Installation

**With 1.1.0 installed:** choose **Restart to Update** in the menu bar (or Settings → About) once Mote has downloaded 1.1.1. The Accessibility permission and the saved key carry over.

**From 1.0 or a fresh install:** see the [1.1.0 installation notes](https://github.com/Prathameshppawar/mote/releases/tag/v1.1.0); the same steps apply with the 1.1.1 files.

To verify a download, compare its SHA-256 with the list below or with `SHA256SUMS.txt`:

```sh
shasum -a 256 -c SHA256SUMS.txt --ignore-missing          # macOS
Get-FileHash .\Mote_1.1.1_x64-setup.exe -Algorithm SHA256  # Windows PowerShell
```
