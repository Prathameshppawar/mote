# Mote v1.0.0

**Mote 1.0: AI that stays in the flow.** Mote is a local-first writing and prompting layer for macOS and Windows. It completes your sentences, fixes your spelling and sharpens your AI prompts in whatever app you're typing in. Tab accepts, Esc dismisses, and nothing you type is ever stored.

## Highlights

- **Inline completion** at your caret, in chat apps, email, AI prompts and notes. Debounced, cancellable and cached, so typing is never blocked.
- **Spelling fixed on your machine**, with no tokens and no network, plus a one-sentence AI grammar check only when a sentence looks risky.
- **Prompt enhancement** in ChatGPT, Claude, Gemini and friends: improve, make precise, make technical, structure, debug, research, explain, expand context, or your own instruction.
- **A command palette everywhere** (⌘⇧Space / Ctrl+Shift+Space) to rewrite, change tone, shorten, summarize, explain, translate or continue any text.
- **Context-aware next steps**: copy an error or an issue link, switch apps, and Mote suggests "Debug this error" or "Create coding task".
- **Hinglish and romanized Marathi, as written.** Mixed-language text is detected and preserved, never auto-translated.
- **A usage dashboard you can trust**: tokens, latency and estimated cost per feature and model, computed locally from metadata only.

## Features

**Assistance**
- Inline completion with up to three alternatives (⌥] / ⌥[, Alt on Windows), a per-field cache, and no repeat of dismissed suggestions.
- Local English spelling correction (82,765-word frequency dictionary with an edit-distance error model) and AI grammar checks for single sentences.
- Prompt hint in AI assistants, eight enhancement styles, custom instructions and "Create prompt".
- Palette actions: fix spelling and grammar, improve, rewrite, professional, casual, clearer, concise, summarize, explain, translate, continue writing. Results can be inserted, replaced or copied.
- "Use copied content" actions: create coding task, analyze issue, debug error, explain code, summarize, draft response, create prompt.

**Intelligence**
- Local field classification (conversation, prompt, code, command, note, search, form) with subtypes, plus an AI classifier when local confidence is low.
- Language detection for English, Hinglish, romanized Hindi and Marathi, mixed English-Marathi and Devanagari, with language-preserving instructions on every request.

**AI provider**
- Groq, with your own API key, behind a provider abstraction.
- Model roles: completion, classification and writing (`qwen/qwen3.8-27b`), reasoning (`openai/gpt-oss-120b`), fallback (`openai/gpt-oss-20b`). All are configurable.
- Retries tuned per feature, automatic fallback, rate-limit backoff, offline detection and cancellation.

**Usage and cost**
- Requests, input/output/reasoning tokens, median and p95 latency, error rate, rate-limit events and estimated cost, for today, 7 days and 30 days.
- Breakdowns by feature and model, daily and hourly charts with table views, and provider rate limits.
- A dated pricing table (Groq list prices as of 2026-10-07) that you can edit. Costs are always labelled as estimates.

**App**
- Menu bar / tray app with status, toggles, pause for an hour and quick links.
- Settings: General, AI Providers, Models, Pricing, Completion, Writing, Context, Privacy, Usage, Keyboard, Excluded Apps, Diagnostics, About.
- Guided onboarding, light and dark themes, and a sanitized diagnostics report for bug reports.

## Privacy

- Text is read only from the focused field, around the caret, after the privacy policy allows it.
- Password managers, password fields, macOS Secure Input and Mote's own windows are never observed. Exclude any other app or window title yourself.
- Requests go straight from your computer to Groq, and only for the feature in use. One switch turns cloud AI off.
- Stored locally: settings, usage metadata and short-lived activity metadata. No typed text, prompts, outputs, clipboard contents, window titles or keys, ever. Your API key lives in the Keychain or Credential Manager.

Read the full [privacy model](https://github.com/Prathameshppawar/mote/blob/v1.0.0/docs/privacy/privacy-model.md).

## Known Limitations

- **Unsigned builds.** The macOS app is ad-hoc signed but not notarized, so Gatekeeper blocks the first launch (use **System Settings → Privacy & Security → Open Anyway**). Windows installers are not code-signed, so SmartScreen asks for confirmation (**More info → Run anyway**).
- **Accessibility after updates (macOS).** Each ad-hoc signed build counts as a new app to macOS. After installing a new version, remove Mote from **Privacy & Security → Accessibility** and enable it again if suggestions stop appearing.
- **Windows is new.** The Windows build is compiled, linted and unit-tested in CI, but 1.0 has had far less hands-on use on Windows than on macOS (developed on macOS 26, Apple Silicon). Please report apps where suggestions are missing or misplaced.
- **App coverage.** Mote can only assist where an app exposes its text fields to accessibility APIs. Terminals, remote desktop clients, games and some custom editors are not supported.
- **Preview model.** The default completion, classification and writing model (`qwen/qwen3.8-27b`) is a preview model on Groq and may be retired at short notice. Mote falls back to `openai/gpt-oss-20b` automatically, and you can choose other models under **Settings → Models**.
- **Estimates, not bills.** Costs use list prices and local token counts. Free tiers, discounts and cached-input pricing are not modelled; Groq's console is the source of truth.
- **One provider.** Groq is the only provider in 1.0. The provider layer is ready for OpenAI-compatible endpoints and local models in a later release.
- **English spelling only.** Spelling suggestions cover English. Romanized Hindi and Marathi words are recognised and left alone, not corrected.
- **No auto-update.** Download new versions from the Releases page.
- **No Linux build.**

## Installation

**macOS**: open the DMG, drag Mote to Applications, open it, allow it under **Privacy & Security → Open Anyway**, then enable it under **Privacy & Security → Accessibility** when onboarding asks.

**Windows**: run `Mote_1.0.0_x64-setup.exe`; no administrator rights are needed. Mote appears in the system tray and onboarding walks you through the rest.

**AI**: paste a Groq API key from [console.groq.com/keys](https://console.groq.com/keys) during onboarding or under **Settings → AI Providers**. Spelling, language and context detection, and the dashboard work without one.

To verify a download, compare its SHA-256 with the list below or with `SHA256SUMS.txt`:

```sh
shasum -a 256 -c SHA256SUMS.txt --ignore-missing          # macOS
Get-FileHash .\Mote_1.0.0_x64-setup.exe -Algorithm SHA256  # Windows PowerShell
```
