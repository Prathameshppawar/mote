# Mote v1.1.2

**Open Mote from Applications or Spotlight to reach Settings, even when its menu bar icon is hidden.**

## Highlights

- **Settings are always one launch away (macOS).** On a Mac with a notch, a crowded menu bar can hide Mote's icon. Opening Mote again from Applications, Spotlight or Launchpad now brings up its Settings window instead of doing nothing.

## Features

- No new features. This release fixes how Mote responds to being opened while it is already running.

## Privacy

No change.

## Supported Platforms

| Platform | Minimum | Download |
|---|---|---|
| macOS, Apple Silicon | macOS 11 | `Mote_1.1.2_aarch64.dmg` |
| macOS, Intel | macOS 11 | `Mote_1.1.2_x64.dmg` |
| Windows x64 | Windows 10 or 11 | `Mote_1.1.2_x64-setup.exe` (installs for your account, recommended) or `Mote_1.1.2_x64_en-US.msi` (installs for all users, needs administrator rights) |

The other files are for the in-app updater: `latest.json` lists the current version, macOS updates come from `Mote_1.1.2_aarch64.app.tar.gz` and `Mote_1.1.2_x64.app.tar.gz`, Windows updates run the installers, and each `.sig` file is the signature the app checks before installing.

## Known Limitations

- If Mote's menu bar icon is hidden, ⌘-drag it towards the clock while it is visible (for example with Finder in front, whose menus are short) to keep it in view.
- Everything listed under [1.1.1](https://github.com/Prathameshppawar/mote/releases/tag/v1.1.1) and [1.1.0](https://github.com/Prathameshppawar/mote/releases/tag/v1.1.0) still applies.

## Installation

**With 1.1.0 or later installed:** choose **Restart to Update** in the menu bar or in Settings → About once Mote has downloaded 1.1.2. The Accessibility permission and the saved key carry over.

**From 1.0 or a fresh install:** see the [1.1.0 installation notes](https://github.com/Prathameshppawar/mote/releases/tag/v1.1.0); the same steps apply with the 1.1.2 files.

To verify a download, compare its SHA-256 with the list below or with `SHA256SUMS.txt`:

```sh
shasum -a 256 -c SHA256SUMS.txt --ignore-missing          # macOS
Get-FileHash .\Mote_1.1.2_x64-setup.exe -Algorithm SHA256  # Windows PowerShell
```
