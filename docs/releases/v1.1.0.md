# Mote v1.1.0

**A one-key prompt enhancer, Mote in VS Code and other Chromium-based apps, and updates that install themselves.**

## Highlights

- **Enhance any prompt with Tab.** Type a prompt in ChatGPT, Claude, Gemini, Copilot, Claude Code or any AI chat box and pause: "Enhance prompt · Tab" appears. Press Tab and Mote rewrites the whole prompt in place. Undo (⌘Z / Ctrl+Z) brings yours back.
- **VS Code and other Chromium-based apps.** Electron apps (VS Code, Slack, Notion, Discord) and Chrome-based browsers keep their accessibility tree off until an assistive tool asks for it. Mote now asks before looking for the field you're typing in.
- **Updates in place.** From this version on, Mote downloads and verifies new versions in the background and installs them when you choose "Restart to Update".

## Features

**Prompt enhancer**
- After a longer pause in an AI prompt box, a completion still on screen gives way to "Enhance prompt · Tab".
- Tab reads the whole prompt, enhances it with your chosen style (Settings → Context → Enhancement style; default: Improve), and replaces it only if you haven't changed it meanwhile.
- Esc cancels; dismissing the hint stops it for that prompt box. If an app doesn't let Mote edit the field, the enhanced prompt goes to your clipboard.
- Prompt boxes are now recognized inside IDEs (Claude Code's "Ask Claude to edit…", Copilot's "Ask Copilot…") and in the Microsoft 365 Copilot app.
- The command palette (⌘⇧Space / Ctrl+Shift+Space) still offers every enhancement style.

**Wider app support**
- Electron apps (VS Code, Slack, Notion, Discord, and others) get the accessibility switch Electron documents for assistive tools.
- Chrome, Edge, Brave, Arc and other Chromium browsers, and apps embedding Chromium, also get the switch VoiceOver uses, so text fields on web pages (ChatGPT, Claude, Gmail, WhatsApp Web) are readable.

**Updates**
- Checks a minute after launch and every six hours; turn it off under Settings → General → Update automatically.
- Each update is verified against a signing key built into the app before it can be installed.
- "Restart to Update" appears in the menu bar / tray menu and in Settings → About, which also has "Check for updates".

## Privacy

- Update checks download the release manifest (`latest.json`) and, when there is a new version, the installer from GitHub. They send no information about you, your text or your usage. Turning off "Update automatically" stops them.
- The prompt enhancer sends the prompt you are enhancing to Groq, only when you press Tab, exactly as the palette's enhancement does.
- Nothing else changed: text stays on your computer except for the request of the feature you're using, and no text is stored.

## Supported Platforms

| Platform | Minimum | Download |
|---|---|---|
| macOS, Apple Silicon | macOS 11 | `Mote_1.1.0_aarch64.dmg` |
| macOS, Intel | macOS 11 | `Mote_1.1.0_x64.dmg` |
| Windows x64 | Windows 10 or 11 | `Mote_1.1.0_x64-setup.exe` (installs for your account, recommended) or `Mote_1.1.0_x64_en-US.msi` (installs for all users, needs administrator rights) |

The other files are for the in-app updater: `latest.json` lists the current version, macOS updates come from `Mote_1.1.0_aarch64.app.tar.gz` and `Mote_1.1.0_x64.app.tar.gz`, Windows updates run the installers, and each `.sig` file is the signature the app checks before installing.

## Known Limitations

- **Accessibility once more (macOS).** 1.1 is signed with Mote's own certificate instead of ad hoc. macOS treats it as a new app once: if suggestions don't appear, open System Settings → Privacy & Security → Accessibility, select Mote, remove it with –, then add it again with + (from Applications) and switch it on. Later updates keep the permission.
- **New Microsoft Teams and new Outlook.** These apps embed Microsoft WebView2, which exposes its text to assistive tools unreliably. Mote switches accessibility on for them, but may still see nothing.
- **VS Code's screen reader mode.** When Mote switches on VS Code's accessibility tree, VS Code may turn on its "Screen Reader Optimized" mode (shown in the status bar), which is also what makes the text in its editors readable. If you'd rather keep the normal mode, set `"editor.accessibilitySupport": "off"` in VS Code; Mote then still works in text boxes inside extension panels, such as Claude Code's prompt box, but sees little or nothing in VS Code's own editors, including the Copilot chat input.
- **Not notarized.** Builds are signed with Mote's own certificate, not an Apple Developer ID, so the first manual install still needs **Open Anyway** in Privacy & Security. In-app updates don't.
- **Updating from 1.0.** 1.0 has no updater: install 1.1 manually once; later versions arrive in the app.
- Everything listed under 1.0's known limitations about app coverage, Windows testing, the preview Groq model and cost estimates still applies.

## Installation

**macOS**: open the DMG and drag Mote to Applications (replace 1.0 if asked). If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway**, then re-enable Mote under **Accessibility** as described above.

**Windows**: run `Mote_1.1.0_x64-setup.exe`; it upgrades an existing installation.

From now on, new versions appear as **Restart to Update** in the menu bar.

To verify a download, compare its SHA-256 with the list below or with `SHA256SUMS.txt`:

```sh
shasum -a 256 -c SHA256SUMS.txt --ignore-missing          # macOS
Get-FileHash .\Mote_1.1.0_x64-setup.exe -Algorithm SHA256  # Windows PowerShell
```
